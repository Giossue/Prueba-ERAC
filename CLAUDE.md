# Reservas deportivas

Proyecto de práctica con HTML, CSS, JavaScript, PHP y PostgreSQL, sin frameworks. Seguir las reglas de `rules.md`: español en interfaz, comentarios, documentación y base de datos, y código sencillo de explicar.

Consultar `README.md` para preparar la base de práctica, ejecutar el servidor y usar la API. Las consultas usan sentencias preparadas, los datos se muestran con `textContent` y las entradas se validan en el servidor. Los errores de base de datos se registran sin exponerlos al cliente.
